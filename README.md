Welcome to **HemiToolkit**, a comprehensive suite of over 20 everyday digital utilities designed with an uncompromising focus on modern aesthetics and data privacy. Built entirely with vanilla web technologies and top-tier client-side libraries, it guarantees that **your files never leave your device**. No server uploads, no data collection—just instant, secure processing right in your browser.

## ✨ Key Highlights

* 🔒 **100% Secure & Private:** All file processing (PDF manipulation, image compression, etc.) happens locally in your browser. Zero server interaction.
* 🎨 **Ultra-Premium UI/UX:** Features a sleek, modern glassmorphism aesthetic, 3D hover tilt effects, and smooth GSAP animations. No standard or "sidebar-heavy" layouts here.
* 🌗 **Triple Theme Support:** Seamlessly switch between Light, Dark, and OLED (Pure Black) modes for optimal viewing.
* ⚡ **Zero Build Step:** Plug and play. No npm installs, node modules, or build pipelines required. 
* 📱 **Fully Responsive:** Beautifully optimized for both desktop and mobile web experiences.

## 🧰 The Toolkit

**📄 PDF Organization & Conversion**
* **HTML to PDF:** Native vector engine conversion with live A4 preview.
* **Merge & Split:** Combine multiple PDFs or extract specific page ranges seamlessly.
* **Compress PDF:** Reduce file sizes drastically by optimizing internal images.
* **Format Conversion:** Scan to PDF via camera, Image to PDF, and PDF to JPG.
* **Remove / Extract Pages:** Strip out unwanted pages or save specific ones as a new file.

**✏️ PDF Editing & Security**
* **Sign PDF:** Draw, capture, and embed your signature directly onto documents.
* **Watermark & Numbers:** Add custom text overlays, opacity controls, and pagination.
* **Rotate & Metadata:** Fix page orientations instantly and edit hidden Title/Author tags.
* **Protect & Unlock:** Encrypt PDFs with robust passwords or strip existing passwords (if known).

**🛠️ Developer & Media Utilities**
* **Image Compressor & Converter:** Reduce JPG/PNG/WEBP sizes with live quality sliders and format swapping.
* **JSON Tools:** Instantly format, clean, or minify JSON payloads.
* **Password Generator:** Create highly secure, customizable passwords with a single click.
* **QR Generator:** Generate and download custom-colored QR codes for links and text.
* **Color Picker:** Grab HEX, RGB, and HSL values instantly with a visual interface.

## 🚀 Getting Started

Since HemiToolkit relies on Content Delivery Networks (CDNs) for its frontend libraries, it requires an active internet connection to load the UI frameworks. However, **all file processing remains strictly offline and client-side**.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/hemanthnanu-tech/HemiToolkit.git](https://github.com/hemanthnanu-tech/HemiToolkit.git)

2. **Launch the app:**
Navigate to the project folder and simply double-click index.html to open it in your favorite web browser.

3.  **Deploying (Optional):**
Because this is a static site, you can easily host this project for free on GitHub Pages, Vercel, or Netlify by simply deploying the main directory.

**💻 Tech Stack**
Core: HTML5, CSS3, Vanilla JavaScript

Styling: Tailwind CSS

Animations: GSAP

PDF Manipulation: PDF-lib, PDF.js, jsPDF

Alerts & UI: SweetAlert2, Canvas Confetti
